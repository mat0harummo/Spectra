# Spectra

MR-игра для **Meta Quest 3** на Unity. Реальная комната становится полем битвы:
игрок отмечает места, которые хочет убрать, там появляется слизь; убрав место по-настоящему, он стирает слизь и зарабатывает монетки,
в фазе боя отбивается от призраков купленным оружием (лазерный пылесос, плазменная метла).
