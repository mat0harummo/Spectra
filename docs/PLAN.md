# Spectra: план разработки

MR-игра для Meta Quest 3 на Unity. Реальная комната становится полем битвы:
сначала игрок убирает виртуальную грязь, потом отбивается от призраков.

Каждый этап маленький и заканчивается тем, что можно надеть шлем и что-то проверить.

| # | Этап | Что получится в шлеме |
|---|------|------------------------|
| 1 | Основа MR | Видна реальная комната (passthrough), игра находит пол и столы и отмечает их маркерами |
| 2 | Грязь | На полу и столах появляются пятна слизи в случайных местах |
| 3 | Уборка | Луч из контроллера стирает пятна, за каждое начисляются монетки |
| 4 | Фазы игры | Таймер уборки, потом переход в фазу боя, простой счёт на экране |
| 5 | Призраки | Призраки летают по комнате, пачкают убранные места и атакуют игрока |
| 6 | Оружие | Лазерный пылесос стреляет по призракам, у призраков есть здоровье |
| 7 | Магазин | Между фазами за монетки покупаются и улучшаются оружия (плазменная метла и т.д.) |
| 8 | Полировка | Звуки, эффекты, меню, баланс, сборка APK |

## Структура папок

```
Assets/Spectra/
  Scripts/
    Room/      этап 1: работа с комнатой (MRUK)
    Dirt/      этапы 2–3
    Game/      этап 4
    Ghosts/    этап 5
    Weapons/   этапы 6–7
  Prefabs/
  Materials/
  Scenes/
```

## Правила кода

- Один скрипт отвечает за одно дело.
- Скрипт короткий, обычно до 60–80 строк.
- Настройки выносим в `[SerializeField]`, чтобы менять их в инспекторе без кода.
